# S20 - Speech Service
 
This document describes the Core Speech Service (S20) in the Telcenter system.

## Overview

The Core Speech Service (S20) is responsible for handling speech-to-text
and text-to-speech functionalities within the Telcenter system.
It provides APIs for converting spoken language into written text
and vice versa, enabling seamless communication between users and AI agents.

# A38

This is the group of APIs offered
by the [S20 - Speech Service](../services/core/S20_Speech_Service.md).

This API consists of 1 API.

## A38

This API is based on HTTP.

**Direction:** Any Service → S20

[OpenAPI specification](./A38-openapi.json)

It should be noted that the audio file format
for STT is `WAV` with `16 kHz` sampling rate,
`16 bits` per sample, and `Mono` channel.

Meanwhile, TTS returns MP3 audio files.

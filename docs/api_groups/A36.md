# A36 Group

This is the group of APIs between
the [S01 - Consultation Service](../services/core/S01_Consultation_Service.md)
and [S19 - Conversation Analysis Service](../services/core/S19_Conversation_Analysis_Service.md)

This API consists of 2 API(s).

## A36a

**Direction:** S01 sends to S19.

This API is based on RabbitMQ, with JSON payloads.

The API has the following events.

### A36a Event: `rating_changed`

Message body format:

```ts
{
    "event": "rating_changed",
    "content": {
        "conversation_id": string,
        "rating": {
            "old": null | integer,
            "new": integer
        }
    }
}
```

Note that the old rating can be `null`
or an integer.

### A36a Event: `new_message`

Message body format (depends on database
schema of S01):

```ts
{
    "event": "new_message",
    "content": {
        "message": {
            "id": string,
            "sender_type": string, // one of "CUSTOMER", "AI_AGENT", "HUMAN_AGENT"
            "sender_id": string,
            "content": string
        },
        "conversation": {
            "id": string,
            "customer_satisfaction": number,
            "summary": string
        }
    }
}
```

## A36b

**Direction:** S19 sends to S01.

This API is based on RabbitMQ.

The API has the following events.

### A36b Event: `update_message_emotion`

Message body format:

```ts
{
    "event": "update_message_emotion",
    "content": {
        "message_id": string,
        "emotion": string // one of "Positive", "Negative", "Neutral"
    }
}
```

### A36b Event: `update_conversation_summary`

Message body format:

```ts
{
    "event": "update_conversation_summary",
    "content": {
        "conversation_id": string,
        "summary": string
    }
}
```

### A36b Event: `update_customer_satisfaction`

Message body format:

```ts
{
    "event": "update_customer_satisfaction",
    "content": {
        "conversation_id": string,
        "customer_satisfaction": number
    }
}
```
